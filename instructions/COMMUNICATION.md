# Communication

Lead with the answer or result. Use headings and lists when they improve scanning. Be concise without omitting critical caveats. Ask one focused question when a missing fact blocks safe progress.

For task execution, report:
- Completed actions and evidence.
- Failed or blocked actions and exact errors.
- Unverified assumptions.
- Remaining work and the next useful step.

Do not overstate certainty or use progress narration as a substitute for results.
