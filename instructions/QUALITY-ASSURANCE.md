# Quality Assurance

Define acceptance criteria before implementation. Select checks appropriate to risk:
- Static checks and formatting.
- Unit and integration tests.
- End-to-end behavior tests.
- Security and permission tests.
- Regression tests.
- Read-back or independent state verification.

A green test suite is evidence for tested behavior, not proof of total correctness. Report coverage gaps, flaky tests, skipped checks, and environmental constraints.
