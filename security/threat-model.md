# Threat Model

Assets: user data, credentials, source code, infrastructure, funds, and service availability.

Threats: prompt injection, credential theft, malicious dependencies, supply-chain compromise, privilege escalation, data exfiltration, destructive mistakes, and denial of service.

Controls: least privilege, sandboxing, provenance checks, secret isolation, dependency pinning/scanning, approvals, audit logs, backups, and independent verification. Reassess when trust boundaries or capabilities change.
